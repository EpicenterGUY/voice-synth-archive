# 데이터 소스 계획

## 현재

### Niconico Snapshot Search API
현재 앱의 핵심 데이터 소스.

사용:
- 제목
- 설명
- 태그
- 업로드 시각
- 조회수
- 댓글
- 마이리스트
- 좋아요
- 썸네일
- 곡 길이

Cloudflare Worker를 통해 브라우저 CORS 문제를 우회한다.

## 다음 단계

### VocaDB
곡 엔티티의 기준 데이터베이스 후보.

예정 용도:
- 다국어/별칭 제목
- 아티스트/P명
- 보컬
- 여러 PV 링크 통합
- 앨범/발매 관계
- Niconico 외 누락 후보 확보

### Piapro
- 가사/텍스트 보조 탐색
- 창작물 관계 확인

### YouTube
- Niconico에 없는 공식 업로드
- 삭제/재업로드 후보 보완

### 일반 웹 검색
전문 데이터베이스에서 찾지 못했을 때만 확장 수색.

## 원칙

인터넷 전체 검색을 처음부터 수행하지 않는다.

1. 구조화 DB에서 후보 생성
2. 니코동 등 원본 플랫폼에서 검증
3. 부족할 때 외부 웹으로 확장

이렇게 해야 커버, MAD, 재업로드, 번역글 등의 노이즈를 줄일 수 있다.

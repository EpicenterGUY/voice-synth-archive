# 기억 복원 탐정 설계

## 목적

사용자가 제목을 잊어버린 음성합성곡을 **기억의 조각만으로 다시 찾게 하는 것**이 핵심 목표다.

## 단서 종류

- 제목 일부 / 가사 조각 / P명
- 한국어 자연어
- 한국어 → 일본어/한자 추정
- 보컬 / 엔진
- 업로드 시기
- 조회수대 / 곡 길이
- 장르 / 분위기 / 악기
- MV / 썸네일 특징
- 리듬게임 / 노래방 등의 수록 기억
- 직접 그린 그림 / MV 캡처
- 허밍 / 원곡 일부 녹음
- 확실히 아닌 조건

## 수사 흐름

1. 단서 1개부터 후보 생성
2. 확실한 구조화 단서로 우선 필터
3. 제목/설명/태그 매칭 점수화
4. 한국어 단서를 일본어/한자로 확장
5. 이미지/오디오 특징을 보조 점수로 사용
6. 후보가 많으면 정보량이 큰 추가 질문 제안
7. 사용자의 `이 곡 아님` / `이 느낌에 가까움` 피드백 반영
8. 최종 후보를 일치 이유와 함께 표시

## 앞으로 강화할 부분

- VocaDB 후보 데이터 연동
- YouTube / Piapro / 일반 웹 확장 수색
- 가사 색인
- CLIP 계열 이미지 임베딩
- 허밍 멜로디 contour + DTW
- 원곡 audio fingerprint
- 후보군을 가장 잘 나누는 질문 자동 선택
- 곡별 통합 엔티티(VocaDB/Niconico/YouTube/Piapro 링크 통합)
